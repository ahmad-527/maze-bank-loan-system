# Normative and provider references

Checked 30 October 2026. These sources are **outside the 200-paper count**. Recheck versions and product applicability before implementation/release. None supplies certification by association.

| Reference | Verified state / use | Boundary |
|---|---|---|
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/) and [publication history](https://www.w3.org/standards/history/WCAG22/) | W3C Recommendation, 12 December 2024 version; target AA for in-scope web content. | Requires criterion-level and manual assessment; not all disability needs are covered and legal conformance requires separate applicability analysis. |
| [OWASP ASVS](https://asvs.owasp.org/) | Stable 5.0.0, published 30 May 2025; versioned web/service controls. | Scope/assurance depth follow risk; not every requirement applies identically. |
| [OWASP MASVS releases](https://github.com/OWASP/masvs/releases) | Listed stable 2.1.0; mobile security/privacy reference. | Avoid obsolete blanket level claims; select applicable controls/tests and record actual verification. |
| [NIST SSDF publications](https://csrc.nist.gov/Projects/ssdf/publications) | Listed final SSDF 1.1 (2022); 1.2 revision listed as draft (17 December 2025). | Do not label the draft a final standard. Process guidance does not establish vulnerability freedom. |
| [Core Web Vitals](https://web.dev/articles/vitals) | LCP 2.5s, INP 200ms, CLS 0.1 “good” boundaries at p75, segmented by mobile/desktop. | Provider guidance; distinguish field distributions from lab checks and these baselines from superiority. |
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines) / [Material](https://m3.material.io/) | Platform design references to consult for the actual platform and interaction. | Not competitors, user validation or a licence to copy protected assets. No hands-on platform app benchmark is claimed here. |
